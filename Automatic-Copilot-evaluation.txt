ISSUES & MISSING ELEMENTS
------------------------------------------------------------------------
- [Notebook 1] Non-vectorized gradient descent: compute_gradients_loop is
  defined but never integrated into a training loop. There is no run that
  trains the model using the loop-based gradients, so the mandatory
  "non-vectorized gradient descent" step is only half-satisfied.
- [Notebook 1] The markdown description imports list mentions "pandas" as a
  required library, but pandas is neither imported nor used. Minor
  documentation inconsistency.
- [Notebook 2] No side-by-side convergence comparison for M1, M2, M3; losses
  are printed textually and scatter plots are shown individually, but a
  combined convergence plot would make the comparison more explicit.
- [Notebook 2] Feature normalization (normalize_features) is applied
  inside the model loop but the normalization parameters (mu, sigma) for
  inference in section 8 come from the last loop iteration (M3), which is
  correct but implicit and not explicitly documented.

TA FEEDBACK TO STUDENT
------------------------------------------------------------------------
This is a solid, well-structured submission that clearly demonstrates
understanding of regression from first principles. The mathematical
derivations are presented alongside their code equivalents, and the
conceptual questions show genuine engagement with the astrophysical domain.

The most important fix for a resubmission would be in Notebook 1: add a
gradient_descent_loop function that calls compute_gradients_loop and runs
a complete training loop. Compare its output (loss curve or final parameters)
to the vectorized version to demonstrate that both approaches converge to the
same solution — this is the pedagogical point of having both.

In Notebook 2, consider adding a single plot that overlays the three
convergence curves (M1, M2, M3) to make it immediately visually clear how
the richer feature sets accelerate and lower the final loss. A brief comment
explaining that the mu/sigma used for inference come from the M3 normalization
would also improve readability.

Overall, the work meets the assignment objectives and the cloud execution
evidence is well-documented. Good job.
